02 / GET STARTED

Install OP Client.

  1. Install Fabric Loader

    Run the Fabric installer, select Minecraft 1.21.11, and install the client profile.

  2. Add both mod files

    Download Fabric API for 1.21.11 and OP Client. Put both JAR files in your Minecraft mods folder. Create the folder if it doesn’t exist.

  3. Launch and open the Click GUI

    Start the Fabric 1.21.11 profile in the launcher. Once in game, press Right Shift to open the Click GUI.
