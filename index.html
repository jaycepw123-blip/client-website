RELEASE 1.0.0 FABRIC MOD

OP Client

A client-side mod for Minecraft: Java Edition. Toggle tools like Zoom and Fullbright from an in-game menu, and set your own keybinds.

Minecraft 1.21.11 only. Requires Fabric Loader and Fabric API.

Play in single-player or on servers that allow the modules you enable.

02 / GET STARTED

Install OP Client.

  1. Install Fabric Loader

    Download and run the Fabric installer. On the Client tab, change the Minecraft version to 1.21.11 (the installer picks the newest version by default), keep the latest loader, and click Install.

  2. Add both mod files

    On Modrinth, open the newest Fabric API version for 1.21.11 and click Download. If you haven’t already, download the OP Client JAR.

    In the Minecraft Launcher, open Installations and use the folder icon next to your Fabric profile to open its game directory. Put both JARs in the mods folder there, or create it if needed. These are the default paths:

    • Windows: %appdata%\.minecraft\mods
    • macOS: ~/Library/Application Support/minecraft/mods
    • Linux: ~/.minecraft/mods

  3. Launch and open the Click GUI

    In the Minecraft Launcher, select the fabric-loader-1.21.11 installation and click Play. Once in game, press Right Shift to open the Click GUI.
