# OP Client

Static download and installation site for OP Client, a Fabric mod for Minecraft: Java Edition **1.21.11 only**. The site uses plain HTML and CSS and requires no build.

## Preview locally

From the repository root, run `python3 -m http.server 8000` and open http://localhost:8000.

## GitHub Pages

Under **Settings → Pages**, choose **Deploy from a branch** and select **main** with **/(root)**. The site URL is https://jaycepw123-blip.github.io/client-website/.

Release files are served from `downloads/`.
